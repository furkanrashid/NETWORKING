Components of Computer Networking – Detailed Notes
1. Introduction to Networking Components
Networking components are the hardware devices, software, and communication media required to establish a computer network.

They help computers and other electronic devices connect, communicate, exchange information, and share resources such as files, printers, applications, and internet connections.

Example: When you connect your laptop to the internet, networking components such as a router, modem, network interface card (NIC), and transmission media work together to establish communication.

Networking components are broadly divided into three categories:
1. End Devices
2. Intermediary Devices
3. Transmission Media
We will understand each component in detail.

2. End Devices
End devices are the devices located at the beginning or end of a communication process. They are also called host devices.

They are responsible for sending and receiving data over a network.
A. Server








hackernoon.com


A server is a computer or system that provides services, resources, or information to other computers over a network.

The computers that request these services are called clients.

Functions of a Server:
- Stores and manages data.
- Provides files and applications to clients.
- Handles requests from multiple users.
- Manages network resources.
- Provides security and access control.
Examples of servers:
Server Type	Function
Web Server	Hosts websites
File Server	Stores and shares files
Mail Server	Manages emails
Database Server	Stores and manages databases
Print Server	Manages printing requests

Example: When you open YouTube, your device sends a request to YouTube's servers, which provide the requested video and other information.
B. Client

A client is a computer or device that requests services, data, or resources from a server through a network.

A client generally depends on a server to access particular services.

Functions of a Client:
- Requests information from servers.
- Receives data and services.
- Accesses shared resources.
- Communicates with other network devices.
Examples:
- Desktop computers
- Laptops
- Smartphones
- Tablets
Example: When you open a website using your laptop, your laptop acts as a client and the web server provides the website.

3. Intermediary Devices
Intermediary devices are networking devices that connect end devices and help transfer data from one network device to another.

They control, forward, direct, or manage network traffic.

The major intermediary devices are:
A. Hub








trendnet.com


A hub is a basic networking device used to connect multiple computers or devices in a Local Area Network (LAN).

It operates at the Physical Layer (Layer 1) of the OSI model.

When a hub receives data from one connected device, it broadcasts that data to all other connected devices, regardless of the intended destination.

Functions of a Hub:
- Connects multiple computers in a LAN.
- Broadcasts incoming data to all connected ports.
- Provides a central connection point.
- Does not identify the intended destination device.
Example:

Suppose four computers (A, B, C, and D) are connected to a hub.

If computer A sends data to computer C, the hub sends that data to B, C, and D as well. Only C accepts and processes the data intended for it.

Disadvantages:
- Causes unnecessary network traffic.
- Less secure because data is broadcast.
- All connected devices share bandwidth.
- More collisions can occur in half-duplex Ethernet.
B. Switch








turbosquid.com


A switch is a networking device used to connect multiple devices within a LAN.

It operates primarily at the Data Link Layer (Layer 2) of the OSI model.

A switch uses MAC addresses to identify devices and forward data only to the appropriate destination port, when the destination is known.

Functions of a Switch:
- Connects multiple devices within a LAN.
- Learns and stores MAC addresses.
- Forwards data to the correct destination port.
- Reduces unnecessary network traffic.
- Supports efficient communication between devices.
Example:

Suppose computers A, B, C, and D are connected to a switch.

When computer A sends data to computer C, the switch checks its MAC address table and forwards the frame to computer C's port.

Advantages:
- Reduces unnecessary traffic.
- Improves network performance.
- Provides better bandwidth utilization.
- Reduces collisions through dedicated full-duplex links.
C. Router








helptechco.com


A router is a networking device that connects two or more different networks and forwards data packets between them.

It primarily operates at the Network Layer (Layer 3) of the OSI model.

A router uses IP addresses to determine the best path for forwarding data packets.

Functions of a Router:
- Connects different networks.
- Forwards packets based on IP addresses.
- Selects the appropriate route for data transmission.
- Connects local networks to the internet.
- Often provides NAT, DHCP and basic firewall features.
Example:

Your home Wi-Fi router connects your home network to the internet.

When you search for something on Google, the router forwards your request towards the internet and delivers the returning data to your device.

Advantages:
- Connects different networks.
- Helps manage network traffic.
- Supports communication between different IP networks.
- Can provide network security features.

A repeater is a networking device that regenerates or retransmits signals to extend the communication distance of a network.

It operates at the Physical Layer (Layer 1) of the OSI model.

As signals travel over long distances, they can become weak. A repeater receives the signal, regenerates it, and sends it forward.

Functions of a Repeater:

    Regenerates weak signals.

    Extends network coverage.

    Helps overcome signal attenuation.

    Allows communication over longer distances.

Example: An Ethernet repeater can help extend a wired network beyond the normal cable segment distance.

A bridge is a networking device that connects two or more LAN segments and forwards data based on MAC addresses.

It operates at the Data Link Layer (Layer 2) of the OSI model.

A bridge examines the destination MAC address and decides whether to forward or filter a frame.

Functions of a Bridge:

    Connects different LAN segments.

    Filters network traffic.

    Uses MAC addresses to forward data.

    Helps reduce unnecessary traffic between network segments.

Example: A bridge can connect two sections of an office LAN so devices in both sections can communicate.
G. Gateway
SRX5400 Documentation | Juniper Networks

A gateway is a networking device or system that connects networks using different protocols or architectures.

It acts as an entry and exit point for communication between networks.

Unlike a basic router, a gateway may also translate data formats or protocols.

Functions of a Gateway:

    Connects different types of networks.

    Translates protocols when required.

    Allows communication between dissimilar systems.

    Acts as an entry and exit point for network traffic.

Example: A gateway can connect an IP network with an industrial network that uses a different communication protocol.

Important: In ordinary IP networking, the term default gateway usually refers to the router or Layer 3 device through which a computer sends traffic destined for other networks.
