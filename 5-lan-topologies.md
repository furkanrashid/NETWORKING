LAN Topologies (Local Area Network Topologies)
1. What is LAN Topology?
A LAN (Local Area Network) topology refers to the physical or logical arrangement of computers, cables, switches, and other devices connected within a local area network.

In simple words, LAN topology describes how computers are connected and how data travels between them.

LAN topologies are mainly of the following types:
1. Bus Topology
2. Star Topology
3. Ring Topology
4. Mesh Topology
5. Tree Topology
6. Hybrid Topology

2. Types of LAN Topologies
1. Bus Topology








masterymind.co.uk


Definition: In bus topology, all computers are connected to a single central cable called the backbone cable.

Working:
- All computers share one communication cable.
- When a computer sends data, it travels through the main cable.
- All connected computers receive the signal, but only the intended device accepts the data.
- Terminators are placed at both ends to prevent signal reflection.
Advantages:
- Easy to install.
- Requires less cable.
- Low installation cost.
Disadvantages:
- If the main cable fails, the entire network stops.
- Network performance decreases when more computers are connected.
- Difficult to troubleshoot.
2. Star Topology








dsw.aau.edu.et


Definition: In star topology, all computers are connected to a central device, such as a switch or hub.

Working:
- Every computer has a separate connection to the central device.
- When one computer sends data, it passes through the switch or hub.
- The central device forwards the data to the destination.
Advantages:
- Easy to install and manage.
- Failure of one cable does not affect other computers.
- Easy to identify network problems.
- Good performance with switches.
Disadvantages:
- If the central switch or hub fails, the entire network stops.
- Requires more cables.
- Installation cost is higher than bus topology.
3. Ring Topology








tutorialspoint.com


Definition: In ring topology, each computer is connected to two neighbouring computers, forming a circular connection.

Working:
- Data travels from one computer to another around the ring.
- Each computer passes the data to the next computer.
- Some ring networks use a token-passing mechanism to control data transmission.
Advantages:
- Organized data transmission.
- Token passing helps prevent data collisions.
- Predictable performance under controlled traffic.
Disadvantages:
- Failure of one connection can disrupt the network in a basic ring.
- Adding or removing computers can be difficult.
- Troubleshooting can be complicated.
4. Mesh Topology








boardinfinity.com


Definition: In mesh topology, computers or network devices are connected through multiple links to provide different paths for data transmission.

There are two types:
- Full Mesh: Every device is directly connected to every other device.
- Partial Mesh: Only some devices have multiple direct connections.
Advantages:
- Highly reliable.
- Multiple paths are available for data transmission.
- Failure of one connection does not necessarily stop the network.
Disadvantages:
- Expensive to install.
- Requires more cables and ports.
- Complex to maintain.
5. Tree Topology








imagetodrawio.com


Definition: Tree topology is a combination of star and bus topologies in which devices are arranged in a hierarchical structure.

Working:
- A main device connects to multiple secondary devices.
- Each secondary device connects to other computers.
- Data travels through different levels of the network.
Advantages:
- Easy to expand.
- Suitable for large networks.
- Easy to manage different departments.
Disadvantages:
- Failure of the main backbone can affect large sections.
- Requires more cables.
- Installation and maintenance can be expensive.
6. Hybrid Topology








fintechshield.co.in


Definition: Hybrid topology is a combination of two or more different network topologies, such as star, bus, and ring.

Working:
- Different network topologies are connected together.
- Each section can use a different topology.
- They work together as one larger network.
Advantages:
- Flexible network design.
- Easily expandable.
- Reliable when properly designed.
Disadvantages:
- Expensive to implement.
- Complex installation.
- Requires skilled network administrators.

3. Comparison of LAN Topologies
Topology	Structure	Main disadvantage
Bus	Single backbone cable	Main cable failure
Star	Central switch/hub	Central device failure
Ring	Circular connection	Ring disruption
Mesh	Multiple connections	High cost
Tree	Hierarchical structure	Backbone dependency
Hybrid	Combination	Complex design

4. Which LAN topology is most commonly used?










Star Topology

Star topology is commonly used in modern wired LANs, such as offices, schools, computer laboratories and homes.

It is preferred because it is easy to manage, troubleshoot and expand.
